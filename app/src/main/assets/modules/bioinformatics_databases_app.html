SECTION 01

Introduction to Bioinformatics

Definition
Bioinformatics is an interdisciplinary science that applies principles of computer science, mathematics, and statistics to acquire, store, organise, analyse, and interpret biological data — especially large-scale data from genomics, proteomics, and molecular biology.

The word combines biology + informatics. The explosive growth of DNA sequence data from genome projects made it impossible to process this information manually — bioinformatics provides the tools and frameworks to handle it computationally.

Scope of Bioinformatics

🗄️ Data Management

Building and maintaining biological databases for DNA, RNA, protein, and structural data.

🔍 Sequence Analysis

Comparing DNA/protein sequences to find similarities, predict function, and study evolution.

🧬 Genomics

Analysing whole-genome data — mapping, annotating, and comparing complete genomes.

🌳 Phylogenetics

Reconstructing evolutionary relationships between species using molecular data.

🧪 Drug Discovery

Identifying drug targets, modelling protein–ligand interactions, and virtual screening.

🩺 Medical Genomics

Identifying disease-causing mutations and supporting precision medicine approaches.

Exam Point
Bioinformatics is often described as the application of information technology to the study of living things, usually at the molecular level. Three defining activities: data storage (databases), data analysis (algorithms/tools), and knowledge extraction (biological interpretation).

⚠️ Common Confusions

Bioinformatics Databases vs Search Tools
A bioinformatics database (e.g., GenBank, EMBL) is a structured repository that stores biological data — like a library. A search tool (e.g., BLAST, Entrez) is a software program that queries those databases to find matching sequences — like a library catalogue. You use search tools to access databases; the database itself does not search anything.
Bioinformatics Databases vs Sequence Analysis Methods
A database passively stores sequences and associated annotations. A sequence analysis method (e.g., pairwise alignment, BLAST search, phylogenetic tree building) is an algorithm or computational technique that processes and compares sequences to extract biological meaning. Analysis methods use databases as their data source but are a separate concept.
Primary Databases vs Secondary Databases
Primary databases (e.g., GenBank, EMBL, DDBJ, PDB) store original, experimentally determined data submitted directly by researchers. Secondary databases (e.g., UniProt/Swiss-Prot, Pfam, KEGG) are derived or curated databases that add interpretation, annotations, or patterns extracted from primary data — they are not raw submission archives.
Quick Revision
  • Bioinformatics = biology + computer science + mathematics — manages and analyses large biological datasets
  • Three core activities: data storage, data analysis, and knowledge extraction
  • Databases store data; search tools query it; analysis methods interpret it — three distinct concepts
  • Primary databases store original experimental data; secondary databases add curated interpretation
  • The Human Genome Project (completed 2003) generated massive sequence data — bioinformatics made it usable
SECTION 02

Need for Bioinformatics

The Data Explosion
By 2023, GenBank alone contained over 250 billion nucleotide base pairs from more than 2 billion sequence records. New sequencing technologies (Next-Generation Sequencing) generate gigabytes of data per experiment. No human team can analyse this manually — bioinformatics tools are essential.

Why Bioinformatics Is Indispensable

1
Data Storage at ScaleGenome sequences contain billions of nucleotides. Physical storage and rapid retrieval of sequence records for millions of organisms requires structured digital databases.
2
Data RetrievalScientists need to quickly find specific genes, organisms, or sequence features from among billions of records — impossible without database search tools like Entrez or SRS.
3
Sequence Comparison and AnalysisFinding similar sequences across species helps infer gene function, evolutionary relationships, and disease relevance — requires computational alignment algorithms.
4
Global Data SharingResearch benefits from shared, publicly accessible data. Bioinformatics infrastructure ensures sequences submitted anywhere in the world become available to all researchers instantly.
5
Annotation and InterpretationRaw sequences must be annotated — genes, regulatory regions, and features identified — before they are biologically meaningful. Bioinformatics tools automate this process.
Quick Revision
  • The genomic era generates data far too large for manual analysis — bioinformatics is essential
  • Five core needs: storage, retrieval, comparison/analysis, global sharing, and annotation
  • Next-Generation Sequencing (NGS) has accelerated sequence data production exponentially
  • Without bioinformatics, genome projects like the Human Genome Project could not be completed
SECTION 03

Biological Databases

Definition
A biological database is an organised collection of biological data stored in a computer system so that it can be retrieved, updated, and analysed efficiently. Databases form the foundation of bioinformatics — they are where experimental data is deposited and from where it is accessed globally.

Types of Biological Databases

📂 Primary Databases

Store original, experimentally determined data submitted directly by researchers. Data is uninterpreted.

  • GenBank (NCBI, USA)
  • EMBL Nucleotide Sequence Database (EBI, Europe)
  • DDBJ (DNA Data Bank of Japan)
  • PDB (Protein Data Bank — structures)

📑 Secondary Databases

Derived from primary databases through expert curation and computational analysis. Add functional annotation and classification.

  • UniProt / Swiss-Prot (proteins)
  • Pfam (protein families)
  • KEGG (metabolic pathways)
  • OMIM (human genetic disease)
Exam Point
The three major international nucleotide sequence databases — GenBank, EMBL, and DDBJ — are all primary databases. Together they form the International Nucleotide Sequence Database Collaboration (INSDC).
Quick Revision
  • Biological database = organised, computer-stored collection of biological data for retrieval and analysis
  • Primary databases store original experimental data (submitted by researchers)
  • Secondary databases add expert curation and annotation to primary data
  • GenBank, EMBL, and DDBJ are the three main primary nucleotide sequence databases
  • Together they form INSDC — International Nucleotide Sequence Database Collaboration
SECTION 04

Nucleotide Sequence Databases

Definition
A nucleotide sequence database is a type of biological database that stores DNA and RNA sequence data — along with associated information (organism, gene name, function, publication) — and makes this data freely accessible to researchers worldwide.

Nucleotide sequence databases are the most fundamental resource in molecular biology. When a researcher sequences a gene or genome, they submit the sequence to one of the three international databases. The data is then shared globally within 24 hours.

Why Nucleotide Databases Are Critical

📤 Submission Archive

Many journals require database submission before publication — ensuring all newly determined sequences become public.

🔬 Research Foundation

Every BLAST search, phylogenetic analysis, and gene cloning project begins with database-retrieved sequences.

🌍 Global Access

Free, open access to all submitted sequences — democratising molecular biology research worldwide.

📋 Annotation Storage

Stores not just sequences but functional annotations — gene location, protein product, known variants, and literature references.

Quick Revision
  • Nucleotide databases store DNA/RNA sequences + associated biological annotation
  • Journal submission policies require database deposition — ensuring public availability
  • Used as the starting point for virtually every molecular biology research project
  • Free, open access to billions of sequences from all organisms on Earth
SECTION 05

GenBank

🇺🇸 USA · NCBI

GenBank — The US National Nucleotide Sequence Database

GenBank is the comprehensive, publicly accessible nucleotide sequence database maintained by the National Center for Biotechnology Information (NCBI), which is part of the National Institutes of Health (NIH) in the United States. Established in 1982, it is the world's largest annotated sequence archive.

Key Features of GenBank

📅 Founded

Established in 1982 at NCBI, National Institutes of Health (NIH), Bethesda, USA.

🔢 Scale

Over 250 billion nucleotide bases from >2 billion sequence records (2023); grows by ~10% per year.

🌐 Access Tool

Entrez search system and BLAST tool allow searching and comparing sequences online.

📄 Flat File Format

GenBank flat file format: each record has LOCUS, DEFINITION, ORGANISM, FEATURES (genes), ORIGIN (sequence).

🔗 Integrated

Linked to PubMed (literature), taxonomy, protein, structure, and other NCBI databases.

🤝 INSDC Member

Exchanges data daily with EMBL (EBI) and DDBJ — all three databases share identical records within 24 hours.

Type of Data Stored

  • DNA and RNA sequences from all organisms (bacteria, viruses, plants, animals, humans)
  • Genome sequences — complete chromosomes, organellar genomes
  • Expressed Sequence Tags (ESTs), Sequence-Tagged Sites (STSs)
  • Annotations: gene boundaries, coding sequences, protein products, regulatory regions
  • Associated metadata: organism name, taxonomy, tissue, literature references, submitter information
Exam Point
The accession number is a unique identifier assigned to every sequence in GenBank (e.g., AY123456). It is permanent — once assigned, it never changes. This allows researchers worldwide to unambiguously cite and retrieve a specific sequence.

Quick Revision
  • GenBank = US nucleotide sequence database maintained by NCBI (NIH), founded 1982
  • World's largest sequence archive — over 250 billion base pairs
  • Searched using Entrez; sequence comparison done using BLAST
  • Each sequence gets a unique permanent accession number (e.g., AY123456)
  • Member of INSDC — shares all data daily with EMBL and DDBJ
SECTION 06

EMBL Nucleotide Sequence Database

🇪🇺 Europe · EBI

EMBL — The European Nucleotide Archive (ENA)

The EMBL Nucleotide Sequence Database (now known as the European Nucleotide Archive — ENA) is maintained by the European Bioinformatics Institute (EBI), part of the European Molecular Biology Laboratory (EMBL), headquartered in Hinxton, Cambridge, UK. It is Europe's primary repository for nucleotide sequence data.

Key Features

📅 Founded

Established in 1980 — the world's first nucleotide sequence database, predating GenBank by two years.

🌍 Coverage

Receives direct submissions from European and global researchers. Mirrors GenBank and DDBJ data daily.

🔎 Access Tools

SRS (Sequence Retrieval System) and FASTA tools for searching and comparing sequences.

📄 EMBL Format

Uses its own EMBL flat file format: ID, AC (accession), DE (description), OS (organism), SQ (sequence).

🔗 Cross-linked

Integrated with UniProt, PDB, Ensembl, and InterPro — the EBI hosts many interconnected biological databases.

🤝 INSDC Member

Founding member of INSDC — exchanges all data with GenBank and DDBJ within 24 hours of submission.

Data Stored

  • Nucleotide sequences from all organisms — DNA and RNA
  • Whole-genome shotgun sequences and high-throughput sequencing data
  • Environmental sequences (metagenomics)
  • EST (Expressed Sequence Tags) and STS (Sequence-Tagged Sites)
  • Full annotations: feature tables, taxonomy, literature cross-references
Historical Note
The EMBL database was established in 1980, two years before GenBank. It was one of the pioneering efforts in making biological sequence data publicly available — a revolutionary concept at the time.
Quick Revision
  • EMBL database (now ENA) = European primary nucleotide sequence database, maintained by EBI/EMBL
  • Oldest nucleotide database — founded 1980 (predates GenBank by 2 years)
  • Headquarters: European Bioinformatics Institute (EBI), Hinxton, Cambridge, UK
  • Search tools: SRS (Sequence Retrieval System) and FASTA
  • INSDC founding member — synchronised with GenBank and DDBJ daily
SECTION 07

DDBJ — DNA Data Bank of Japan

🇯🇵 Japan · NIG

DDBJ — The Japanese Nucleotide Sequence Database

The DNA Data Bank of Japan (DDBJ) is maintained by the National Institute of Genetics (NIG) in Mishima, Shizuoka, Japan. It is the Asian hub of the INSDC and accepts sequence submissions primarily (but not exclusively) from Japanese and Asian researchers.

Key Features

📅 Founded

Established in 1986 — the most recently founded of the three INSDC databases. Became fully operational in 1987.

🌏 Focus

Primary submission hub for Japanese and Asian researchers; receives data internationally as well.

🔎 Access Tools

Sakura submission system; DDBJ Search and BLAST interfaces for retrieval and comparison.

📄 Format

Uses the same flat file format as GenBank — facilitating seamless data exchange across all three databases.

🧬 Specialisation

Notable for large-scale sequencing of Japanese crop and model organisms; strong in rice and marine organism genomics.

🤝 INSDC Member

Full INSDC member since 1987 — synchronises all accepted submissions with GenBank and EMBL within 24 hours.

Data Stored

  • Nucleotide sequences from all organisms, with emphasis on organisms studied in Japan and Asia
  • Genome sequence data including large-scale shotgun projects
  • EST, STS, and GSS (Genome Survey Sequences)
  • Annotated sequences with taxonomy, feature tables, and literature links
  • Data from unique Japanese model organisms (e.g., Oryzias latipes — medaka fish)
Exam Point
DDBJ uses the same accession number system as GenBank and EMBL. A sequence submitted to DDBJ is assigned an accession number and this record becomes available in all three databases within 24 hours — the same record, the same accession number.
Quick Revision
  • DDBJ = DNA Data Bank of Japan, maintained by NIG (National Institute of Genetics), Mishima, Japan
  • Founded 1986 — youngest of the three INSDC member databases
  • Primary Asian hub for sequence submission; notable for Japanese and marine organism genomics
  • Uses Sakura submission system; BLAST for sequence comparison
  • Full INSDC member — shares all data daily with GenBank and EMBL
SECTION 08

Data Sharing, Collaboration & Global Data Flow

The INSDC Partnership
GenBank, EMBL, and DDBJ together form the International Nucleotide Sequence Database Collaboration (INSDC). This means a sequence submitted to any one of the three databases is automatically shared with the other two — becoming globally accessible within 24 hours. A researcher in Australia accessing GenBank sees exactly the same data as one in Japan using DDBJ.

Exam Point — INSDC Principles
  • One submission, three databases: submitting to any one makes data available in all three
  • 24-hour synchronisation: all three databases are kept identical within one day
  • Free and open access: all sequence data in INSDC databases is freely available to anyone
  • Mandatory for publication: most journals require sequence deposition before publishing
Quick Revision
  • INSDC = International Nucleotide Sequence Database Collaboration (GenBank + EMBL + DDBJ)
  • A sequence submitted to any one database is shared with the other two within 24 hours
  • Data flow: lab → submission → accession number assigned → INSDC sync → global free access
  • All three databases contain identical records — different interfaces, same data
  • Journal policies require INSDC submission before publication — ensuring data becomes public

SECTION 10

Applications of Nucleotide Databases

🧬
Gene Identification

Compare unknown sequences against database entries to identify gene identity, structure, and probable function by homology.

🔍
Sequence Comparison (BLAST)

BLAST searches compare a query sequence against millions of database sequences to find similar genes across species in seconds.

🌳
Evolutionary Studies

Retrieve homologous sequences from many organisms to build phylogenetic trees and trace evolutionary relationships.

🩺
Disease Research

Identify mutations in disease-related genes, find pathogen sequences, and understand genetic basis of inherited disorders.

🌾
Crop Biotechnology

Retrieve sequences of genes controlling yield, disease resistance, and nutritional quality for targeted crop improvement.

💊
Drug Discovery

Identify drug target sequences in pathogen genomes, compare with host sequences to design selective therapeutic strategies.

🔬
Primer Design

Retrieve target gene sequences to design specific PCR primers for diagnostic assays, gene cloning, and research.

🦠
Pathogen Surveillance

Track emergence of new pathogen variants — critical during outbreaks (e.g., COVID-19 variant tracking via GISAID linked to INSDC).

Exam Point
BLAST (Basic Local Alignment Search Tool) is the most widely used bioinformatics tool — it compares a query sequence against all sequences in GenBank and returns similar sequences ranked by statistical significance (E-value). It is available free at NCBI.
Quick Revision
  • 8 key application areas: gene ID, sequence comparison, evolution, disease research, crop biotech, drug discovery, primer design, pathogen surveillance
  • BLAST (at NCBI) is the most used bioinformatics tool — searches GenBank in seconds
  • Phylogenetic trees built from database sequences reveal evolutionary relationships
  • COVID-19 pandemic demonstrated real-time use of nucleotide databases for variant tracking

SECTION 13

Summary & Revision Bullets

  • Bioinformatics applies computer science and mathematics to store, retrieve, and analyse biological data — especially sequences.
  • Three core bioinformatics activities: data storage (databases), data analysis (tools/algorithms), knowledge extraction (interpretation).
  • Databases store data; search tools (e.g., BLAST, Entrez) query databases; sequence analysis methods (e.g., alignment) process retrieved data — three distinct concepts.
  • Primary databases store original experimental data (GenBank, EMBL, DDBJ, PDB); secondary databases add curated annotation (UniProt, KEGG).
  • Nucleotide sequence databases store DNA/RNA sequences with full annotations from all organisms.
  • GenBank: NCBI, USA, founded 1982 — world's largest; Entrez + BLAST; accession numbers.
  • EMBL/ENA: EBI, UK, founded 1980 — oldest; SRS + FASTA; strong European resource integration.
  • DDBJ: NIG, Japan, founded 1986 — newest; Sakura submission; Asian research hub.
  • INSDC = International Nucleotide Sequence Database Collaboration — synchronises GenBank, EMBL, DDBJ within 24 hours.
  • Sequence data flow: lab → submission → accession number → INSDC sync → global free access.
  • Applications: gene identification, BLAST searches, phylogenetics, disease research, drug discovery, primer design, pathogen tracking.

SECTION 14

Glossary

Bioinformatics
The interdisciplinary science applying computer science and mathematics to store, retrieve, and analyse biological data, especially molecular sequences.
Database
An organised collection of data stored in a computer system that can be efficiently searched, retrieved, and updated.
Nucleotide Sequence
The order of nucleotide bases (A, T, G, C for DNA; A, U, G, C for RNA) in a DNA or RNA molecule.
GenBank
The US primary nucleotide sequence database maintained by NCBI (NIH); founded 1982; the world's largest annotated sequence archive.
EMBL / ENA
The European primary nucleotide sequence database (now European Nucleotide Archive) maintained by EBI; the oldest such database, founded 1980.
DDBJ
DNA Data Bank of Japan — the Japanese primary nucleotide sequence database maintained by NIG; founded 1986; part of INSDC.
INSDC
International Nucleotide Sequence Database Collaboration — the partnership between GenBank, EMBL, and DDBJ for daily synchronisation of all sequence records.
Accession Number
A unique permanent identifier assigned to each sequence record deposited in an INSDC database (e.g., AY123456). It never changes.
Data Retrieval
The process of searching a database and extracting specific records — performed using tools like Entrez (GenBank) or SRS (EMBL).
BLAST
Basic Local Alignment Search Tool — the most widely used bioinformatics tool; compares a query sequence against all database sequences to find similar ones.
Primary Database
A database storing original, experimentally determined biological data submitted directly by researchers, without additional curation.
Sequence Analysis
Computational methods (alignment, BLAST search, phylogenetic analysis) used to compare and interpret sequence data — distinct from database storage.

Frequently Asked University Exam Questions

1. Define bioinformatics. Explain its scope and importance in modern biology.
Define bioinformatics (biology + computer science + mathematics; storage, retrieval, and analysis of biological data). Scope: data management, sequence analysis, genomics, phylogenetics, drug discovery, medical genomics. Importance: manages genomic data explosion; enabled Human Genome Project; essential for BLAST searches, database-based research, precision medicine. Mention three core activities: storage, analysis, knowledge extraction.
2. What are nucleotide sequence databases? Write a note on GenBank — its origin, features, and importance.
Define nucleotide sequence databases (store DNA/RNA sequences with annotations; free global access). GenBank: maintained by NCBI (NIH), USA; founded 1982; world's largest annotated archive; search tools Entrez and BLAST; accession numbers; flat file format (LOCUS, DEFINITION, FEATURES, ORGANISM, ORIGIN); INSDC member; importance — universal reference for molecular biology; enables gene identification, BLAST searches, evolutionary studies.
3. Compare GenBank, EMBL, and DDBJ under the headings: organisation, country, search tools, year of establishment, and collaboration.
Table format recommended. GenBank (NCBI/NIH, USA, 1982, Entrez/BLAST); EMBL/ENA (EBI/EMBL, UK, 1980, SRS/FASTA); DDBJ (NIG, Japan, 1986, Sakura/BLAST). All three are INSDC members — synchronised daily. EMBL is oldest; GenBank largest; DDBJ is Asian hub. Same accession number system. Data flow: submission → accession assigned → 24h global sync.
4. Explain the INSDC — International Nucleotide Sequence Database Collaboration. Why is it important for global science?
INSDC = partnership between GenBank, EMBL, and DDBJ. Daily synchronisation — submitting to any one makes data available in all three within 24 hours. Importance: (1) no duplication of submission effort for researchers; (2) ensures global access to all sequences regardless of submission location; (3) prevents data siloing; (4) free and open — democratises molecular biology; (5) mandatory submission policies in journals ensure all sequence data becomes public. Mention data flow diagram: lab → submission → accession → sync → global access.
5. Discuss the applications of nucleotide sequence databases in research and medicine. Give examples.
Eight applications: (1) gene identification — BLAST matches unknown sequences; (2) sequence comparison — BLAST across species; (3) evolutionary studies — phylogenetic trees from retrieved sequences; (4) disease research — mutation identification, pathogen genomes; (5) crop biotech — trait gene retrieval; (6) drug discovery — target sequence identification; (7) primer design — PCR and cloning; (8) pathogen surveillance — COVID-19 variant tracking. Mention BLAST (NCBI) as the tool that makes most of these possible.
