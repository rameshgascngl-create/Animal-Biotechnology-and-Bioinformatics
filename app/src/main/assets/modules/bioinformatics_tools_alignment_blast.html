Bioinformatics Tools: Sequence Alignment, BLAST and Structure Viewers

Pairwise and Multiple Alignment · BLAST · FASTA · RasMol · Swiss-PdbViewer

Once sequences and structures are stored in databases, we need tools to compare and view them. This module explains how sequences are aligned, how BLAST and FASTA find relatives in huge databases, how protein structures are visualised, and where bioinformatics is applied. A live calculator lets you build a Needleman–Wunsch or Smith–Waterman matrix yourself.

🧬 Chapter 1

Sequence Alignment: Concepts and Pairwise Alignment

Alignment arranges sequences to reveal similarity that may reflect shared ancestry, structure or function.

Sequence alignment
A way of arranging DNA, RNA or protein sequences to identify regions of similarity, by introducing gaps where needed, that may be due to functional, structural or evolutionary relationships.
TermMeaning
IdentityPercentage of positions with exactly the same residue
SimilarityPercentage of positions with identical or chemically similar residues (positive score in the matrix)
HomologyShared ancestry. It is either present or absent; not a percentage
OrthologuesHomologous genes in different species, from speciation
ParaloguesHomologous genes in the same species, from duplication
Pairwise alignment: two types
GlobalLocal
AlignsEntire length of both sequencesOnly the best matching regions
AlgorithmNeedleman–Wunsch (1970)Smith–Waterman (1981)
Best forClosely related, similar-length sequencesDivergent sequences; shared domains or motifs
Matrix ruleScores can be negative; trace back from bottom-rightScores floored at 0; trace back from highest score to 0
Scoring
  • DNA: simple match / mismatch (for example +1 / −1).
  • Proteins: substitution matrices PAM (Dayhoff, evolutionary model) and BLOSUM (Henikoff, from conserved blocks; BLOSUM62 is the default in BLAST).
  • Gap penalties: linear, or affine (gap opening + extension), because one long gap is more likely than many short ones.
Dynamic programming in one line

Cell rule

F(i,j) = max of [ F(i−1,j−1) + s(ai,bj)  |  F(i−1,j) + gap  |  F(i,j−1) + gap ]  (Smith–Waterman also includes 0).

Try it: alignment calculator
Press Align to fill the matrix and trace back.

Use letters A–Z. Change the scores or switch to local mode to see how the result changes. Dot-plots and the DP matrix show the same idea visually.

Interpreting results
  • E-value: expected number of hits with this score or better by chance in a database of that size. Smaller is better; < 10−5–10−10 usually suggests significance.
  • Bit score: normalised score, independent of the scoring system; higher is better.
  • Query coverage and percent identity should be read together with the E-value.
BLAST versus FASTA
BLASTFASTA
AuthorsAltschul et al. (1990), NCBILipman and Pearson (1985)
MethodWord matches, then ungapped / gapped extension to HSPsFinds diagonal regions of k-tuple matches, rescores the best with a matrix, then does a banded Smith–Waterman
Word size3 (protein), 11 (DNA) defaultktup 1–2 (protein), 4–6 (DNA)
StrengthVery fast, widely used, strong statisticsMore sensitive for distant matches at smaller ktup
VariantsPSI-BLAST (profile iterations), BLAT, DELTA-BLASTFASTA, SSEARCH, FASTX/Y

Sensitivity vs speed

Heuristic searches may miss weak matches that an exact Smith–Waterman search would find, but they run orders of magnitude faster.

Protein Structure Visualisation: RasMol and Swiss-PdbViewer

Structures from the Protein Data Bank (PDB files) can be rotated, coloured and measured on screen.

A PDB file is a text file listing the 3-D coordinates (x, y, z) of each atom. Visualisation software reads it and draws the molecule in many styles.

Typical tasks

  • Identify active-site residues and ligands.

Summary & Exam Revision

Key points and model answers likely to appear in university examinations.

Key exam points
1
Global = Needleman–Wunsch (1970); local = Smith–Waterman (1981); both use dynamic programming.
2
Scoring: match/mismatch (DNA); PAM and BLOSUM (proteins); linear or affine gap penalties.
3
Identity and similarity are percentages; homology is shared ancestry (orthologues vs paralogues).
4
MSA: progressive using a guide tree (Clustal); iterative (MUSCLE, MAFFT).
5
BLAST (Altschul, 1990): words → seeds → HSP extension → E-value / bit score.
6
blastn, blastp, blastx, tblastn, tblastx.
7
FASTA (Lipman and Pearson, 1985): k-tuple diagonals, rescoring, banded SW.
8
RasMol and Swiss-PdbViewer display PDB coordinates; Swiss-PdbViewer also models and superimposes.
9
Bioinformatics applies to genomics, proteomics, drug design, medicine, agriculture and evolution.
Short-answer questions

Click a question to reveal the model answer.

Q.1Differentiate global and local alignment.▼

Global (NW) aligns entire sequences and suits similar sequences of similar length. Local (SW) aligns only the best-matching regions and suits divergent sequences or shared domains.

Q.2What are PAM and BLOSUM matrices?▼

Substitution matrices giving scores for replacing one amino acid with another. PAM is based on an evolutionary model of point accepted mutations; BLOSUM is derived from conserved blocks of related proteins (BLOSUM62 is the default).

Q.3Explain how BLAST works.▼

The query is split into words, matching words (seeds) are found in the database, seeds are extended in both directions to form HSPs, and significance is expressed as bit score and E-value.

Q.4List the BLAST programs.▼

blastn, blastp, blastx, tblastn and tblastx, differing in the type of query and database and use of translation.

Q.5Compare BLAST and FASTA.▼

Both are heuristic similarity searches. BLAST uses word hits and extension to HSPs and is faster; FASTA uses k-tuple diagonals followed by rescoring and a banded Smith–Waterman, and can be more sensitive at small ktup.

Q.6What is multiple sequence alignment and name two tools?▼

Alignment of three or more sequences to reveal conserved residues, done progressively using a guide tree. Tools: Clustal Omega, MUSCLE, MAFFT, T-Coffee.

Q.7Name two protein structure visualising tools and their uses.▼

RasMol (fast display in wireframe, spacefill, cartoon styles) and Swiss-PdbViewer (analysis, superposition, mutation and homology modelling).

Q.8State four applications of bioinformatics.▼

Genome annotation, drug discovery (docking), personalised medicine, evolutionary analysis/phylogeny, crop improvement.

📖 Glossary

Key Terms & Glossary

Important terms in simple language.

Alignment
Arrangement of sequences to show similarity.
Gap
A position in an alignment representing an insertion or deletion.
Dynamic programming
Method that solves a problem by combining optimal solutions to sub-problems.
PAM
Point Accepted Mutation matrices from evolutionary models.
BLOSUM
Block Substitution Matrix derived from conserved protein blocks.
HSP
High-scoring Segment Pair: a local alignment reported by BLAST.
E-value
Expected number of chance hits with the same or better score.
Bit score
Normalised alignment score independent of scoring matrix.
Query
The sequence you submit for a database search.
Guide tree
Tree that decides the order of progressive alignment.
PDB file
Text file of atomic coordinates of a macromolecule.
Homologue
A sequence sharing common ancestry with another.
